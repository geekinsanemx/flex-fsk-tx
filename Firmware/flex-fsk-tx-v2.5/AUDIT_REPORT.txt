✅ NVS Configuration (Preferences)

   - save_core_config() / load_core_config()
   - Survives factory reset

✅ SPIFFS Configuration
   - DeviceSettings struct (JSON format)
   - save_runtime_settings() / load_runtime_settings()

✅ Persistent Logging System
   - /serial.log file (32KB max, 8KB rotation)
   - RAM buffer 2KB con flush cada 1s
   - Timestamps (RTC o uptime)
   - logMessage() / logMessagef()
   - AT+LOGS?N / AT+RMLOG

✅ RF Amplifier Control
   - GPIO configurable con validación
   - Polarity selection (active-high/low)
   - Stabilization delay (20-5000ms)
   - ON antes TX, OFF después TX

✅ Battery Monitoring
   - getBatteryInfo() - voltage + percentage
   - Low battery alert (10% threshold, 15% hysteresis)
   - Power disconnect alert (3-reading confirmation)
   - 60s polling interval

✅ RTC Support (DS3231)
   - Optional compilation flag (RTC_ENABLED)
   - rtc_init() / rtc_sync_system_time()
   - Boot from RTC time
   - NO NTP dependency

✅ Message Queue
   - 10 message FIFO queue
   - Thread-safe con portMUX
   - queue_add_message() / queue_get_next_message()

✅ Core 0 Transmission Task
   - transmission_task() en Core 0
   - Isolated RF timing
   - xTaskCreatePinnedToCore()

✅ EMR (Emergency Message Resynchronization)
   - send_emr_if_needed()
   - Sync burst primer mensaje
   - Re-sync cada 10 minutos
   - Pattern: {0xA5, 0x5A, 0xA5, 0x5A}

✅ Message Truncation
   - Auto-truncate a 245 + "..." = 248 chars
   - truncate_message_with_ellipsis()

✅ Capcode Validation
   - validate_flex_capcode()
   - 3 rangos válidos con gap detection

✅ Watchdog Timer
   - 60s timeout
   - 120s boot grace period
   - watchdog_init() / watchdog_feed()

✅ Factory Reset
   - GPIO 0 button (30s hold)
   - AT+FACTORYRESET command
   - Display feedback
   - Preserves NVS PPM correction

✅ Heartbeat LED
   - 4 blinks cada 60s
   - led_heartbeat_update()
